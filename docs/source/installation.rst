Requirements
------------

You need Python 3.11 or later to run GriSPy. You can have multiple Python
versions (3.x) installed on the same system without problems.


Installation
------------

The easiest way to install is using pip::

    $ pip install grispy

This will install the latest stable version on PyPI.

If you want to use the latest development version from github, unpack or clone the `repo <https://github.com/mchalela/GriSPy>`_ on your local machine, 
change into the project root, and install with pip::

    $ pip install -e .
